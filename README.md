# Blog_Empotrados

Para hacer el desarrollo de la máquina expendedora, he implementado una arquitectura basándome en Multitarea Cooperativa y una Máquina de Estados Finitos (FSM).  
El objetivo principal de la práctica es cumplir con el requisito de reactividad, donde para ello hay que eliminar por completo el uso de retardos bloqueantes, los delays, en el flujo principal.
